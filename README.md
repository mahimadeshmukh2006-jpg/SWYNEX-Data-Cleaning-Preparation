# SWYNEX Internship Task 1 — Data Cleaning & Preparation

## Project Overview
This project focuses on cleaning and preparing the Titanic passenger dataset using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## Dataset
Titanic passenger dataset from the Seaborn-data public GitHub repository.

## Work Performed
- Inspected dataset structure and data types.
- Identified missing values and duplicate records.
- Standardized inconsistent text values.
- Handled missing values using median, mode and an `unknown` category.
- Corrected data types.
- Removed duplicate rows.
- Validated the cleaned dataset.
- Exported cleaned data and audit reports.

## Results
- Original records: 891
- Cleaned records: 778
- Missing cells after cleaning: 0
- Remaining duplicate rows: 0

## Output Files
- `titanic_cleaned.csv`
- `cleaning_audit.csv`
- `cleaning_summary.txt`
- `data - cleaning.ipynb`

## Conclusion
The Titanic dataset was inspected, cleaned, validated and exported successfully as part of SWYNEX Internship Task 1..
